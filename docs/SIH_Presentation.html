Problem Context

The Enterprise Log Challenge

Why traditional SIEM and Big Data pre-processing fails in modern high-throughput environments.

🚨 Industry Pain Points

  • Format Fragmentation: Devices emit logs in Syslog (RFC 3164/5424), JSON, XML, CEF, and proprietary syntaxes.
  • Fragile Regex Fatigue: Security teams spend weeks manually crafting fragile parsers that break whenever vendors push minor updates.
  • Forensic Loss: Systems discard raw unparsed strings or silently modify fields, destroying legal evidence non-repudiation.
  • Silent DB Tampering: Traditional relational log stores allow malicious actors with DB access to rewrite intrusion records undetected.

🎯 What the SIH Problem Requires

  • Complete Raw Data Preservation: Zero information loss; full original bytes stored with provenance.
  • Self-Learning Onboarding: Auto-cluster novel logs without manual regex engineering.
  • Taxonomic Normalization: Canonical schema mapping (OCSF 4001 Network Activity).
  • Cryptographic Immutability: Mathematical verification proofs for every single log entry.
  • 100% Air-Gapped Operation: Zero external CDNs, cloud APIs, or outbound network egress.

The ULPF Vision: "Ingest Any Protocol → Seal Cryptographically → AI Self-Learn Syntax → Output Canonical OCSF & Parquet Data Lake."

Technical Architecture

End-to-End Pipeline & Microservices

6 containerized services running on isolated internal bridge with zero external leakage.

1. Ingestion Layer (:5140, :5141, :5142)

Wire-speed Syslog UDP/TCP and HTTP REST listeners. Attaches UUIDv4 lineage ID, computes SHA-256 seal, and appends to WORM Zstandard chunks.

2. Integrity Daemon (:5143)

Batches 1,000 logs into SHA-256 Merkle Trees. Signs root hashes with Ed25519 into append-only ledger.jsonl. Provides sub-ms verification.

3. Dual-Path Engine (:8000)

Hot-Path: Deterministic pre-compiled regex.
Cold-Path: Drain3 prefix-tree clustering + TF-IDF semantic mapper + confidence gate.

4. OCSF Normalizer

Validates against OCSF v1.2.0 Class 4001. Invariant: ocsf.metadata.uid == raw_event.lineage_id for non-repudiation.

5. Storage & Sinks (:8001)

Apache Parquet columnar Data Lake partitioned by date (data/lake/ocsf_events/) + streaming SIEM forwarder (Splunk HEC, CEF, JSONL).

6. Analyst Web Console (:3100)

Next.js 15 UI: Real-time EPS telemetry, 1-Click Pack Promotion queue, and visual Merkle tree audit viewer.

Pipeline Topology: Network Logs → Ingestion WORM → Merkle Ledger → Dual-Path Router → OCSF Normalizer → Parquet Lake / SIEM Stream → Web Console

Core Innovation

Dual-Path Routing & Self-Learning Parsing

Eliminating 90% of manual parser engineering through unsupervised template mining.

⚡ The HOT Path (Wire Speed)

  • Deterministic Regex Execution: High-throughput parsing for known patterns (e.g. Cisco ASA, Linux Syslog).
  • Throughput: ~40,000 events/second per core with sub-30μs latency.
  • Direct Dispatch: Immediately normalized into OCSF 4001 and streamed to SIEM/Lake without human intervention.
  • 100% Field Confidence: Exact matching ensures zero semantic ambiguity.

🧠 The COLD Path (AI Self-Learning)

  • Drain3 Prefix-Tree Clustering: Unsupervised streaming clustering that mines log templates (<*>) and isolates variables.
  • TF-IDF Semantic Mapper: Automatically proposes field mappings against the OCSF schema dictionary.
  • Confidence Gate (< 0.85): Low-confidence events enter the Analyst Review Queue with auto-suggested mappings.
  • 1-Click Promotion & RCU Hot-Reload: Analyst confirms → signs with Ed25519 → packs reload in-memory with zero downtime.

Forensics & Security

Cryptographic Provenance & Tamper Demonstration

Mathematical proof guaranteeing log non-repudiation and instant intrusion detection.

🔒 The Cryptographic Architecture

  • Microsecond Leaf Seal: Every raw log payload is content-sealed with SHA-256 upon arrival.
  • WORM Chunk Store: Raw logs append to compressed Zstandard chunks with exact byte-offset indices.
  • 1,000-Event Merkle Trees: Leaves are hashed pair-wise into an immutable Merkle Root.
  • Ed25519-Signed Ledger: Every Merkle root is digitally signed and appended to a hash-chained ledger file.
  • Sub-ms Deep Verification: Given any Lineage ID, ULPF re-verifies raw bytes, leaf hash, Merkle path, and digital signature.

🧪 Live Tamper Drill (Negative Control)

We engineered a live demonstration CLI (tools/tamper_drill.py) to prove tamper detection to evaluators:

Forensic Courtroom Readiness: Even if a root attacker gains administrative database access and rewrites the database rows, the Merkle tree and immutable chunk store detect the discrepancy instantly.

Security & Compliance

Air-Gap Engineering & Defensive Hardening

Designed from ground zero for classified and critical infrastructure environments.

🚫 Zero Egress Networking

  • All 6 containers run on an isolated Docker bridge network (internal: true in airgap compose).
  • Zero outbound connections to Google Fonts, external CDNs, or cloud licensing servers.
  • Validated via automated socket egress drill (tools/check_airgap.py).

🛡️ Principle of Least Privilege

  • All containers drop all root Linux capabilities: cap_drop: ALL.
  • Enforced kernel security: no-new-privileges: true.
  • Run as non-privileged service accounts (node:1000 and appuser:10001).

🔏 Cryptographic Key Hierarchy

  • Ed25519 high-speed elliptic curve digital signatures.
  • Pack signing quarantine: Unsigned or tampered YAML packs are immediately quarantined.
  • Hardware security module (HSM) ready via PKCS#8 key standards.
